MCP 接入说明

块一 · 提供给 AI 的工具
  • list_projects所有项目 + 完成度
  • list_features功能清单（按项目 / 状态过滤）
  • get_feature单个功能详情
  • create_feature录入新功能
  • update_feature修改功能（状态/完成度联动）
  • advance_feature推进状态一步
  • delete_feature删除功能
  • create_project创建项目
  • delete_project删除项目（连同功能）
  • export_markdown导出 Markdown 清单
块二 · 怎么连接（JSON 字段）
{
  "mcpServers": {
    "feature-board": {
      "command": "node",
      "args": ["D:/kaifamanager/mcp-server.js"]
    }
  }
}

把上面的 mcpServers 字段写进 AI 客户端的配置即可连接。 Claude Code / Cursor 等直接认项目根目录的 .mcp.json（本仓库已创建，内容同上）； ZCode 已配好工作区配置，重开会话自动生效。连上后让 AI「看下功能台有哪些待开发功能」即可验证。
